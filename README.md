# 🚗 BMW Website Clone

## Description

This is a **static clone of the official BMW website**, built using only **HTML and CSS**. It is designed to replicate the visual appearance and layout of the original site, showcasing frontend development and design skills using pure, clean code without any JavaScript or frameworks.

---

## Features

- 🔹 Fully static frontend project
- 🔹 Clean and responsive layout
- 🔹 Structured sections for banners, navigation, car showcases, and footers
- 🔹 Pixel-perfect styling using pure CSS
- 🔹 Compatible with all major browsers

---

## Technologies Used

- **HTML5** – For creating the page structure
- **CSS3** – For styling the components and layout
- **Google Fonts** – For custom font styling 

---

## ▶️ How to Run This Project

1. **Clone the Repository**
```bash
   git clone https://github.com/ShubhranshuSh/BMW-Website-Clone.git
```

2. **Open the Project Folder**

3. **Navigate to the HTML folder**

4. **Open index.html in your IDE**

5. **Start the Project**

6. **Use the Live Server extension (if available) in your IDE**

7. **Click "Go Live" to preview in your browser**

### No backend or setup required — purely frontend!
